# EcoConsciência

Site sobre sustentabilidade com **calculadora de emissão de carbono** e **quiz interativo**, feito com HTML, CSS e JavaScript puros.

## Como usar no GitHub Pages

1. Crie um novo repositório no GitHub.
2. Faça upload dos arquivos desta pasta (`index.html`, `style.css`, `script.js` e a pasta `images/`).
3. Acesse **Settings > Pages** no repositório.
4. Em "Source", selecione a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde alguns minutos. O GitHub Pages publicará seu site.

## Estrutura

```
sustentabilidade-site/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    ├── hero.jpg
    └── carbon.jpg
```

## Funcionalidades

- **Hero interativo**: botões de navegação para a calculadora e o quiz.
- **Calculadora de emissão**: estima kg de CO₂/semana com base no transporte e consumo de energia.
- **Quiz de sustentabilidade**: 5 perguntas com feedback visual e placar final.
- **Design responsivo**: se adapta a celulares, tablets e desktops.
